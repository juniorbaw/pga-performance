# Contribution

Ce repository documente un projet collaboratif réalisé dans le cadre de la formation Data Analytics du Wagon.

Les contributions sont les bienvenues sous forme d’améliorations de documentation, de corrections de requêtes, de nouveaux contrôles qualité ou de visualisations complémentaires.

Avant toute modification :

1. Créer une branche dédiée.
2. Documenter les hypothèses et les sources.
3. Ne pas publier de données sensibles, identifiants ou clés d’accès.
4. Vérifier que les changements n’affectent pas le grain des tables analytiques.
