# Sources de données

Les données utilisées dans ce projet proviennent de sources publiques liées au PGA Tour et aux résultats de tournois.

## Familles de données

- résultats de tournois et scores par tour ;
- statistiques de driving ;
- statistiques de jeu de fers ;
- statistiques de putting ;
- données de conditions météorologiques journalières ;
- évolution de la longueur des parcours et des tournois majeurs.

## Avertissement

Les données brutes ne sont pas redistribuées dans ce repository lorsque leur licence, leur provenance ou leur volume ne le permettent pas.

Les tables de travail sont reconstruites via les scripts SQL et les notebooks documentés.
